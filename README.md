## 先说清楚它是什么

市面上大多数「马斯克技能」是这样的：**把他说过的话按主题归归类，做成一个语录库**。你问它问题，它挑几句响亮的话贴给你。

**这个不一样。** 它把马斯克的思考拆成**四层可检索、可回查、带边界的东西**：

| 层 | 是什么 | 规模 | 回答什么问题 |
|---|---|---|---|
| **原则** | 他怎么看世界 | 11 条 | 「制造比设计难」 |
| **情境手册** | 撞上具体处境时怎么办 | **275 节** | 「产能卡住了怎么办」 |
| **推算规程** | 先算什么、跟什么比、什么时候停 | **147 条** | 「这个成本该拆到哪一层」 |
| **案例** | 真实发生过、有结局的先例 | **132 个** | 「上次类似的事，结果怎样」 |
| **证据** | 逐字原文 + 出处 + 置信度 | **1113 张卡** | 「他真说过吗」 |

**规模对比（同样以已开源的马斯克技能为参照）：原则 11 vs 5、案例 132 vs 0、规程 147 vs 8、逐字证据卡 1113 vs 0、原始语料 258 份 vs 0。**

## 三个设计决定，把它和其他技能分开

### 一 · 每条方法都带**失效边界**

这是最容易被忽略、也最要紧的一条。

大多数技能只告诉你「这条方法什么时候用」。**我们告诉你它什么时候不该用。**

比如「成本形状」这条判据 —— 他问的是 `如果产量到了一百万件，它还贵吗`。这条判据只在**单位成本随产量下降**的行业成立。**说这话的当天，他在造火箭。** 你拿它去判断一家手工店该不该扩产，会得出完全相反的结论。

所以每条规程（147/147）都写了：**这条在什么结构、什么量级下会骗你。**

> 一条不知道自己边界的机制，比没有机制更危险 —— 它会让你把一个错的答案执行得很坚决。

### 二 · 语料**是证据，不是内容**

技能里有一条硬规则：

> **借我的判断，不是借我的经历。**
> 你问的是你自己的事，那讲话的主体就得是你。
> **自查**：把回答里所有的「我」换成「他」。
> 句子还成立 → 那是判断。不成立 → 那只是传记。

**这条规则让「马斯克」真的能被借用。** 一个真前辈不会拿自己的传奇当你的答案 —— 他会把判断给你，把故事留下当证据。

### 三 · **不用积分，按处境路由**

275 节手册躺在一个 386 KB 的文件里。**没有索引，任何模型都只能读到它的 13%（文件读取有截断上限）。**

所以每份大文件开头都有**人工构建的索引**：

- `playbooks.md` → **272 行节索引**，每行写「这节回答什么问题」
- `cases.md` → **132 行案例索引**
- `SKILL.md` → 一张**路由表**，把「问钱 / 问人 / 问判断 / 问状态」直接映射到具体节号

**实测**：模型拿到这套结构后，全程用 `grep` 定位 + `sed` 取段，**17 次文件操作，零全文件读取**，精准命中应读的节。

## 里面到底有什么

### 11 条原则（每条含：主张 + 机制 + 逐字原文 + 失效边界 + 落地动作）

第一性原理 / 物理学是法律 / 算法五步 / 最好的零件是没有零件 / 白痴指数 / 造机器的机器 / 质疑要求 / 假设自己是错的 / 极限思维 / 硬核节奏 / 为文明做备份

加上**十道过滤闸**（可判定的是或否，任一道判否就停）和**9 条独有推理模式**（S 曲线定位、攻击约束而非平均值、合取概率、复杂度复利、看呈现物不听努力、物理上限≠需求、先对账…）。

### 275 节情境手册

从「该做什么生意」到「被攻击时怎么办」，从「怎么学一个新领域」到「文明级风险怎么排序」。

**每节写四件事**：什么时候用 · 他怎么说（逐字原文） · 这条讲什么 · 什么时候不成立。

### 147 条推算规程

**这是盲测中被证明最有价值的一层。**

测试发现：模型读完技能能说出马斯克的观点，**但做不出他的动作**。规程层就是补这个洞。

每条写：触发 → 他的原话 → 编号动作 → 失效边界。

例：`把「做出来一个」和「做出一万个」分开算` / `先消灭串行依赖，再谈加速` / `让拍板的人和懂的人是同一个人`。

### 132 个可核查案例

每个带情境、决策、结局（含数字）、以及**反例标记** —— 那些是原则失灵、代价显现、或他公开承认判断错误的时刻。**反例比成功案例更值得读。**

### 1113 张逐字证据卡

每张一条引文 + 出处 + 语料位置 + 置信度。

**置信度分两级**：`high` = 本人亲述（访谈/演讲/官方文件）；`medium` = 第三方转述（传记/书评/他人整理）。

**引用前请照这个区分说明分量。**

### 70 条语感样本 + 表达风格 DNA

句式、确定性分界（对物理用绝对断言、对时间表大量 hedge）、幽默方式、禁忌词汇、段落节奏。

### 已知的盲区与内部矛盾

技能**主动记录了它自己的边界和矛盾**：

- 时间表系统性乐观（他自己承认过，技能里标明「别信他的年份」）
- 方法在物理系统里近乎无敌，**在人系统里失灵**
- **记录了 3 处语料内部矛盾**（同一个决策他有两种互相矛盾的说法）—— 不调和，两处并列，并警告不要拿任一当模板

## 安装

### Pi

```bash
git clone https://github.com/<你的用户名>/elon-musk-wisdom ~/.pi/agent/skills/elon-musk-wisdom
```

### Claude Code / 其他 agentskills.io 兼容 runtime

把 `skills/elon-musk-wisdom/` 整个目录拷到对应 runtime 的 skills 目录即可。

```
<runtime>/skills/elon-musk-wisdom/
├── SKILL.md
├── references/       ← 7 个 .md
└── corpus/           ← 需要你自己抓（见下）
```

### 语料要自己抓

**本仓库不分发第三方语料**（传记、访谈转录、文章 —— 版权不归我们）。见 [THIRD-PARTY.md](THIRD-PARTY.md)。

```bash
python3 tools/fetch_corpus.py --out <skills目录>/elon-musk-wisdom/corpus
```

脚本读 `tools/corpus-sources.json`（**254/258 份带原始 URL**），逐条抓取重建成技能期望的文件名。

抓不到的那几份是出版物（传记、书籍），请自行合法获取。

**不抓语料也能用** —— 技能主体（原则 / 手册 / 规程 / 案例 / 证据卡）全在 `references/` 里。只有「要回去看某场的完整原文」这一个功能需要 corpus。

## 没做到的地方（诚实）

**一 · 人格层有洞。** 幽默、愤怒、兴奋、讽刺、称呼亲近度、公开认错、怎么顶回去 —— 这七个维度没有**专采样本**。`voice.md` 的 70 条语感样本里，笑声标记是 0。表达风格 DNA 里写了「幽默：冷、干、常自嘲」，但没有样本支撑。

**二 · 手册的失效边界覆盖不全。** 规程层 147/147 都有；手册层只有 20/272。**这是下一个要补的。**

**三 · 能力边界。** 它的语料里**没有**县城小生意、本地人情、行业潜规则这类内容。**在资源配置、成本结构、组织、衰退中的取舍、高压决策上它很强；在「你脚下那条街怎么运转」上它一无所知。**

**四 · 英文语料、中文框架。** 引文是英文原文，框架与索引是中文。

## 这个技能是怎么造出来的

由 [Mind-Distill-Factory](https://github.com/) 流水线构建，六阶段闸门（sources → principles → frameworks → skill → package → gallery）全过。

**核心做法**：所有引文由脚本按锚点从语料中**原样抽取**，不手打；写完后由独立脚本逐条回查。**任何改一个词的引文都会被闸门拦下。**

技能包自己记录了 26 条工具缺陷（F1–F26），包括三个典型的「校验器自称通过、实际什么都没查」的案例：

- P3 路径闸门漏扫 `references/*.md`
- 正则字符类不含中文 → 中文语料名全部匹配不到
- 正则排除空格 → 而语料文件名**全都带空格**

**教训写进了代码注释**：闸门报「通过」不等于闸门查过东西 —— 每次新增附件后要**数它扫到了几条路径**，而不是看它脸色。
